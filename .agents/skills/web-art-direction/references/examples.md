# Calibration examples

Use these examples to recognize mechanisms, not to copy the suggested layouts or wording. The appropriate fix depends on the actual content, identity, and task. Delete unnecessary elements before inventing replacements. Preserve deliberately expressive, user-approved choices.

## Headlines, copy and labels

- Manufactured profundity: "Where sound meets soul." -> Omit if it communicates nothing; let the artist's name or work lead.
- Forced contrast: "Not just music. A movement." -> Omit unless there is a real movement to describe; then name it or describe its activity accurately.
- Empty abstraction: "Exploring the spaces between." -> Omit, or retain if it is an actual work title, quotation, or approved artistic statement.
- Fake cultural credibility: "Rooted in the underground. Built for the future." -> Use verified affiliations, places, releases, or other relevant details if the author wants them; otherwise omit.
- Performative minimalism: "Sound. Space. Self." -> Do not replace with another abstract triplet; remove unless it has a meaningful role in the concept.
- Invented positioning: "Redefining the boundaries of electronic music." -> Name the actual work, genre, or release if useful and known.
- Faux-edgy language: "Unfiltered. Uncompromising. Undefined." -> Remove unless these words belong to the author's established voice and have a purpose.
- Generic invitation: "Step into my world." -> Omit rather than adding an unnecessary gateway to the content.
- Manufactured mystery: "For those who exist between frequencies." -> Delete unless intentionally authored as part of the work.
- Redundant eyebrow: "THE ARTIST" above "About the artist" -> Use one heading if needed; no heading may also be appropriate.
- Excessive promotion: "Discover my latest sonic explorations" -> "Releases"; better still, show the release title if the context is already clear.
- Generic action: "Immerse yourself in the latest release" -> "Play" for a player, or "Listen on Bandcamp" for a link that actually goes there.
- Decorative navigation: "Stay connected to the frequency" -> "Instagram" when that is the destination.
- Unnecessary section copy: "Experience the energy live" -> "Dates" or the actual upcoming date.
- Unnecessary heading: "The artist behind the sound" -> "About" when a section label is useful.
- Overlong contact label: "For bookings and creative collaborations" -> "Contact" or "Bookings" depending on the actual purpose; preserve distinctions if they matter.
- Self-described aesthetics: "Raw energy meets refined minimalism" -> Delete; express that direction through the work rather than explaining it.
- Generic business headline: "Unlock the power of seamless collaboration" -> State the actual task, e.g. "Review and approve purchase orders" if that is what the product does.
- Generic feature copy: "Everything you need to succeed" -> Name the actual features and their relevance, or remove the heading if the list is self-explanatory.
- Generic commerce CTA: "Elevate your everyday" -> "Shop jackets" if the destination is the jacket collection.
- Generic portfolio copy: "Crafting digital experiences that inspire" -> Show selected work; use a specific description of the designer's practice if visitors need it.
- Unhelpful error: "Oops! Something went wrong on your journey." -> Describe the actual problem and recovery action, e.g. "Upload failed. Try again." Only state a cause if known.
- Empty state filler: "Your creative journey starts here" -> Explain the missing item and available action, e.g. "No saved tracks."
- Unnecessary urgency: "Don't miss out!" -> Give the real deadline if one exists; otherwise omit.
- Generic social proof: "Trusted by thousands" -> Use a verified count or a relevant attributed testimonial if available and appropriate; never invent it.

## Visual and interaction examples

- Artist homepage: generic hero, subtitle, two CTAs, biography cards, mailing list and testimonials -> Lead with the artist's actual work or identity; arrange only real content such as releases, dates and contact in a deliberate composition. Do not require any of those sections if absent from the brief.
- Portfolio: identical cards with decorative icons and generic project summaries -> Let actual project imagery, titles, scale and sequence establish hierarchy. Keep a uniform grid if systematic comparison is the actual goal.
- Editorial site: every section is a floating rounded container -> Use typographic hierarchy, alignment and whitespace for reading flow; retain a boundary where it marks a genuinely distinct object or action.
- Product interface: every metric has a gradient, icon and status pill -> Emphasize values and meaningful differences; use badges, icons and color for information that needs them. A data dashboard can legitimately use a grid.
- Shop: oversized generic lifestyle hero pushes actual products below the fold -> Give the collection and shopping task appropriate prominence; retain a large campaign image if the brief is explicitly campaign-led.
- Typography: oversized, bold, tightly tracked headline with one italicized accent word -> Revisit the hierarchy and line breaks in relation to the actual subject; preserve expressive contrast if it has a deliberate graphic function.
- Color: unrelated violet glow behind a neutral page -> Remove the glow or develop a palette tied to existing identity or artwork. Do not replace violet with a universally prescribed color.
- Components: an icon in a rounded colored square above every heading -> Remove redundant iconography; retain icons that identify actions or communicate meaning efficiently.
- Motion: every element slides in as the page scrolls -> Keep content immediately available; reserve motion for meaningful state changes, purposeful pacing, or an explicit artistic concept. Respect reduced motion.
- Minimal navigation: hiding essential links behind a cryptic symbol to look experimental -> Make essential destinations discoverable. Preserve unusual navigation only when it supports the intended experience and remains usable.
- Retro identity: generic scanlines, chrome text, grids, glow and grain all piled together -> Choose the few devices that actually relate to the visual language; retain intentional maximalism when that is the brief.
- Minimal identity: replacing every interesting element with a beige background and a trendy serif -> Preserve the strongest distinctive motifs, typography, composition and imagery; remove only unrelated clutter.

## Exceptions and transfer checks

- A real poetic headline, manifesto, song title, campaign line, or piece of fiction may be the main content. Do not rewrite it into a functional label merely because it resembles a smell.
- A symmetrical grid of products, films, or comparable records may be the clearest structure. Do not introduce arbitrary asymmetry to satisfy the skill.
- A landing page can legitimately require a headline, explanation and CTA when visitors need to understand an unfamiliar offering. Improve specificity and hierarchy rather than deleting necessary information.
- An intentionally maximalist club flyer, playful game UI, brutalist portfolio, or conventional public-service site has its own standards. Judge the choices against that brief, not a shared aesthetic.
- A concise label must still be understandable in context and accessible. Do not sacrifice action specificity or instructions for brevity.
- For new work, avoid generating the weak version in the first place. For existing work, review actual rendering and copy before applying any analogy.
